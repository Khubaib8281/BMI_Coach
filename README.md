# 🧮 BMI Coach Console App (C++)

A console-based C++ application that calculates Body Mass Index (BMI) and provides personalized health suggestions based on the result. It supports multiple height units and stores each user's data in a `.txt` file.

---

## 🚀 Features

- ✅ Interactive user input
- ✅ Supports multiple height units:
  - Meters
  - Centimeters
  - Feet & Inches
- ✅ Accurate BMI calculation
- ✅ Health category classification:
  - Underweight
  - Normal
  - Overweight
  - Obese
- ✅ Personalized diet, exercise, and lifestyle suggestions
- ✅ General wellness tips
- ✅ Record saved using file handling (`BMI_records.txt`)
- ✅ Input validation for clean data

---

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling (`<fstream>`)
- Input Validation
- Console-based User Interface
